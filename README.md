I created a marvel database with an App.jsx page and 6 components, the home page, the view characters page, the character details page, the create character page,
the navbar, and the not found page. I wrapped the navbar in an offCanvas to allow the user better visibility of the characters. On the home page I made a title card with 
a background image behind it. On the not found page I used setTimeout and UseNavigate to redirect the user from the not found page back to the home page. On the create character
and edit character pages I created a form using the react bootstrap form components which gave a more polished finish to the forms. On the view characters and view character details
pages I put the characters in their own cards to make the formatting of the character images and info look cleaner. I used a modal for the delete character option to give the user a warning message that they are about 
to delete the character. This was a challenging but enjoyable project!
